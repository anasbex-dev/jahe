# JAHE

**A compiled systems programming language built for control, safety, and performance.**

JAHE is an experimental systems programming language inspired by C and Rust.

## Vision

JAHE aims to combine low-level control, ownership-based memory safety, and native compilation into one language.

## Core Principles

- Hybrid memory management
- Ownership-based safety
- Explicit low-level memory control
- Native compilation
- Modular and optional runtime
- Self-hosting compiler as a long-term goal

## Development Status

Early development — language specification and compiler architecture are being designed.

## Planned Toolchain

- Compiler: Rust bootstrap
- Backend: LLVM
- Runtime: JAHE Runtime
- Source extension: `.jahe`
